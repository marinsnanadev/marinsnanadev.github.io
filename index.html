Projeto 01 / 05

VIOLET

no ar

E-commerce full stack onde o servidor é a fonte da verdade.

Autenticação com JWT, carrinho persistente que se junta à conta no login e checkout para convidados e clientes. O total do pedido é calculado no servidor, nunca confiando no preço enviado pelo navegador.

  • Idempotência com Idempotency-Key: reenvio ou clique duplo não gera dois pedidos.
  • Detecta produto removido ou preço alterado entre o carrinho e a compra.
  • Encontrei e corrigi uma falha IDOR em rotas do carrinho.
  • Mais de 50 testes no back-end (Pytest) e Jest no front.

Stack: React · FastAPI · SQLAlchemy · PostgreSQL · JWT · Pytest · Jest

A loja é fictícia e não processa pagamentos reais. No primeiro acesso, a API pode levar cerca de um minuto para acordar.

Projeto 02 / 05

LiveDesk

código aberto

Chat de suporte em tempo real, um mini Intercom.

Widget para o visitante e painel para o agente, com mensagens ao vivo, presença, indicador de "digitando…" e status e prioridade de cada ticket. Cada mensagem é salva antes de ser transmitida, então o histórico nunca diverge do que foi exibido.

  • Estado durável no banco e estado ao vivo (presença) só em memória.
  • Reconexão com backoff exponencial, sem perder o rascunho nem sobrescrever mensagens novas.
  • Tokens por conversa para visitantes e token de agente nas rotas e WebSockets.
  • Migrations com Alembic e CI que roda os testes em SQLite e PostgreSQL, com lint e build do front.

Stack: FastAPI · WebSockets · React · SQLAlchemy · Alembic · Pytest

Projeto 03 / 05

PriceWatcher

código aberto

Monitor de preços de Amazon e Mercado Livre com coleta agendada.

Você cadastra o link e o preço-alvo; o sistema acompanha o produto e guarda o histórico para o gráfico. As coletas rodam em segundo plano, em fila, e erros de rede não derrubam nada.

  • Scrapers em camadas, com plano B quando a loja muda o HTML.
  • Celery e Redis, com retry, backoff exponencial e jitter para não sobrecarregar as lojas.
  • Cada coleta fica registrada (status, origem do preço, duração, erro).
  • Cerca de 50 testes, com páginas reais salvas como fixtures.

Stack: FastAPI · Celery · Redis · SQLAlchemy · Alembic · React · Pytest

Projeto 04 / 05

Games Dashboard

no ar

Dashboard de dados com IA que só explica números já calculados.

O back-end consulta a RAWG API e calcula as agregações (jogos por ano, nota média, ano de pico). A Gemini API recebe só esse resultado e narra o padrão, sem fazer contas, o que evita números inventados.

  • Valida a resposta da IA antes de exibir; se vier inválida, o painel mostra erro com botão de nova tentativa.
  • Cache (1 h nos dados, 6 h nos insights), rate limit e timeout em toda chamada externa.
  • Cancela respostas antigas quando o filtro muda rápido.

Stack: React · Vite · Chart.js · Express · RAWG API · Gemini API

No primeiro acesso, o servidor pode levar cerca de um minuto para iniciar.
