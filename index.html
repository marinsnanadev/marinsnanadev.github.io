Sobre

Quem escreve o código

Sou uma desenvolvedora full-stack com foco em front-end e mais de um ano de experiência em produtos digitais de mobilidade urbana. Gosto de criar interfaces que organizam a informação, tornam os fluxos mais naturais e funcionam bem em diferentes telas.

Tenho experiência prática com React, TypeScript, JavaScript, Angular, HTML e CSS, além de back-end com Node.js e Python. Me interesso por componentização, acessibilidade, performance e pela conexão entre uma boa interface e uma API bem estruturada. Fora do trabalho, mantenho projetos pessoais full-stack para explorar arquitetura, autenticação e testes automatizados. Inglês fluente para times e documentação técnica.

Projetos

O que eu construí

Quatro estudos de caso do front-end à arquitetura que ninguém vê.

Estudo 01 / 04

VIOLET

em desenvolvimento

Loja virtual full-stack com autenticação de usuários (JWT + hash de senha via PBKDF2), carrinho de compras persistente e checkout com validação e cálculo do pedido no servidor — evitando manipulação de preços pelo cliente. Conta com página de conta do cliente com histórico de pedidos, e API e fluxos principais cobertos por testes automatizados (pytest e Jest).

Stack: React · FastAPI · SQLAlchemy · JWT · Pytest

Estudo 03 / 04

Games Dashboard

em desenvolvimento

Dashboard de análise de dados de games com insights gerados por IA, usando a RAWG API e a Gemini API. O backend agrega os dados (contagem por ano, nota média, ano de pico) antes de enviar ao modelo — que só narra o padrão em linguagem natural, sem fazer contas sozinho, o que evita números alucinados. Respostas ficam em cache por 30 min para economizar chamadas do free tier.

Stack: React · Vite · Express · RAWG API · Gemini API

Estudo 04 / 04

LiveDesk

em desenvolvimento

Chat de suporte ao vivo com presença em tempo real, indicador de "digitando…" e histórico persistido — um mini Intercom/Zendesk. O núcleo do projeto é a separação entre estado durável (mensagens, salvas no banco) e estado ao vivo (presença e digitação, mantidos só em memória no servidor e nunca persistidos), respondendo à pergunta clássica de entrevista: como lidar com múltiplos clientes conectados via WebSocket e o que acontece quando um deles cai.

Stack: FastAPI · WebSockets · React · SQLAlchemy · Pytest
